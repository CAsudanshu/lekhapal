LekhaPal – Install & User Guide

Accounting, inventory, VAT, TDS, IRD e-billing and NFRS financial statements for Nepal.
Developed by CA Sudanshu Mallick · ca.sudanshu@gmail.com

1. Installing

A. On a Windows laptop (works fully offline)

  1. Copy the LekhaPal folder anywhere (e.g. D:\LekhaPal).
  2. Double-click Start LekhaPal (Windows).bat. A small black window opens and LekhaPal opens in Chrome / Edge at http://localhost:8765. Keep the black window open while working.
  3. In Chrome/Edge click the Install icon in the address bar (or menu › Install LekhaPal). It then opens like a normal app from the Start menu. You still start the .bat first each day (or put a shortcut to it in your Startup folder).

B. On a Mac

Double-click Start LekhaPal (Mac).command (first time: right-click › Open). Then install from Chrome as above.

C. From the web link (any laptop or mobile)

  1. Open your web link (see section 6 for how to create it), e.g. https://yourname.github.io/smlekha/.
  2. On Android Chrome: menu › Add to Home screen / Install app. On iPhone Safari: Share › Add to Home Screen.
  3. After the first opening, the app and the bill reader work offline.

Where is my data? Data is stored inside the browser on that device. Each device (and the local .bat version vs. the web link) has its own separate data. To move data between devices use Settings › Download backup file and Restore from backup on the other device. Take backups regularly – clearing browser data deletes the books. On a computer you can switch on Automatic daily backup to a folder (e.g. a Google Drive / OneDrive folder).

2. First start

  1. Create the administrator login (name, email, password). Save the recovery code shown – it resets your password if you forget it.
  2. Entities / clients › + New entity. Choose type (company, proprietorship, partnership, NGO/NPO, cooperative…). A standard Nepal chart of accounts is created automatically.
  3. Fill Legal details (registration, PAN/VAT, capital, directors, shareholders, licences with expiry dates).
  4. Enter opening balances: Upload Excel › Ledgers & opening trial balance and Items & opening stock (templates provided), or type them in Ledgers / Items.
  5. Check Trial balance – it should tally. If it shows "Difference in opening balances", correct the openings.

4. Reports for finalisation

  • Trial balance, Profit & loss, Balance sheet – summary or detailed, any period, Excel / PDF.
  • NFRS statements – Full NFRS, NFRS for SMEs, NAS for Micro Entities, NPO formats: financial position, P&L (& OCI, EPS), changes in equity, cash flow and notes, with previous-year comparatives. Export all to Excel.
  • FS mapping (Ledgers › FS mapping) – move any ledger to a different statement line; Health check cross-verifies TB, negative stock/cash, VAT ledger vs registers, missing PAN, duplicate bills, large cash payments.
  • VAT, TDS & IRD – sales book, purchase book, monthly VAT return figures, VAT reconciliation with returns filed, 1-lakh details (Annex 13) export, missing sales/purchase reconciliation against IRD/third-party data, TDS register, CBMS e-billing, IRD bill register.
  • Stock summary & item ledger (weighted average or FIFO), ageing, ratios, cash flow, bank reconciliation, financial projections (up to 10 years), income tax tools (pool depreciation, advance tax).

5. Users, clients and licences

  • Users & access: give staff or clients their own login, choose which entities and which sections (entries, reports, VAT, documents…) they can use.
  • Licence: each install starts with a 30-day trial (3 entities, 2 users); after that it becomes read-only until a licence key is entered in Settings.
  • For CA Sudanshu Mallick only: Settings › Developer tools › load ADMIN-PRIVATE-LICENSE-KEY.json to generate licence keys (choose client, plan, number of entities/users, expiry) and admin password reset codes. Never share or upload that file. If a client's administrator forgets the password and has no recovery code, they send you the Install ID shown on the "Forgot password" screen; you generate a reset code.

6. Your own web link (hosted on your personal account)

  1. Sign in to github.com with ca.sudanshu@gmail.com (create a free account).
  2. New repository › name smlekha › Public › Create.
  3. "uploading an existing file" › drag in all files and folders inside the LekhaPal folder (not the private key) › Commit.
  4. Settings › Pages › Source: Deploy from a branch, branch main, folder / (root) › Save. After a minute your link is https://<username>.github.io/smlekha/.

Alternative: drag the folder onto app.netlify.com/drop while logged in with the same Gmail.

Publishing Nepal updates to all clients: in the app, Nepal updates › + Add update, then Export for publishing and upload the downloaded updates.json to the repository (replace the old one). Every client who clicks "Check for new updates" while online receives them. Clients using a different copy should set Settings › Updates feed address to https://<username>.github.io/smlekha/updates.json.

Releasing a new version: replace the changed files in the repository and change the version line const CACHE = 'smlekha-v1.0.0' in sw.js (e.g. to v1.0.1) so devices refresh.

7. New in version 1.1

  • Migrate client (menu › Entries): five steps – cut-over date, Tally XML masters (or Excel), previous-year P&L for comparatives, day-book transactions, and verification against the old trial balance.
  • Customers & suppliers: separate party list with PAN, credit days, balances, Excel upload and merging of duplicates.
  • VAT rate per line: 13% by default, Exempt, or "Other %…" for any rate.
  • Locked books: when an entry falls in a locked period you can move or remove the lock right there.
  • Drafts: half-filled entries are saved automatically; continue them from New entry or the dashboard.
  • Comparatives: trial balance, P&L, balance sheet, cash flow, ratios and NFRS statements always show the previous year.
  • Client stock list upload (Items › Upload client stock list): set as opening stock, or adjust books to a physical count.
  • Depreciation (IRD): pool A–D schedule with the 1/3 – 2/3 addition rule, 7% repairs limit, pool E amortisation, "Fill from books" and one-click journal posting.
  • Income tax computation: nature of taxpayer (25% / 30% / 20% / cooperative / exempt NPO / individual slabs), add-backs and deductions, donation & loss limits, TDS and advance tax, interest u/s 118 & 119, fee u/s 117, advance-tax plan, override of any figure, and posting of the tax journal.
  • My firm books (🏢 button at the top): your own firm's accounts. Jobs, fees & collection: record each job by type of work, bill fees and record collections (posted automatically into your firm books, with TDS), attach finalized files and view them inside the app. Fee reports by type of work and by client.
  • Admin & subscriptions (🔑 button): plans (monthly, yearly, 2, 3, 5 years, lifetime – prices editable), subscriber register with expiry alerts, licence key generation, renewals, billing into firm books, and creating client logins.
  • Daily automatic backup: choose a folder for all data and/or a folder per client (also when creating a client). One encrypted file per day, last 30 kept. In Chrome/Edge you may be asked once per session to allow access – click "Allow & back up now" on the dashboard.

8. Two editions – Nepal and International

  • Nepal edition: BS dates, Shrawan–Ashadh year, NPR, VAT/PAN/TDS, IRD (CBMS, Annex 13), IRD pool depreciation, Nepal income tax, NFRS / NFRS for SMEs / NAS for MEs.
  • International edition: normal (AD) dates, any financial-year start month, any currency, VAT / GST / Sales Tax at any rate with monthly or quarterly returns, withholding tax, asset-class depreciation (straight-line or reducing balance), corporate / individual tax computation with country rate and threshold, and IFRS / IFRS for SMEs statements. Country presets: UAE, Saudi Arabia, Qatar, Oman, Bahrain, Kuwait, India, UK, USA, Australia, Singapore, Malaysia, Bangladesh, Sri Lanka, or any other country – every preset value can be changed in Settings › Country, currency & tax.
  • The edition is chosen per client when you create the entity. Your own licence includes both.
  • Selling: in Admin › Subscriptions choose "Edition the client gets" – Nepal, International or Both – and the fee currency. The licence key then only opens that edition; a Nepal-only key cannot open international books and vice versa.

9. Important notes

  • IRD approval: to sell LekhaPal as billing software to businesses that must use IRD-registered / CBMS-connected billing, the software has to be registered with IRD under its electronic billing procedure. The app already follows the main rules (no deletion of invoices, cancel with reason, "Copy of original" on reprints, audit trail, bill register view, CBMS API), but registration is a separate application you make to IRD.
  • CBMS: get API username/password from IRD and enter them in Settings. If the IRD server blocks direct browser connections, use Export in CBMS format.
  • Tax rates, thresholds and due dates in the app are defaults – check after each budget and edit in Updates / Settings.
  • Bill scanning accuracy depends on photo quality; always review before posting.
